# Product Backlog
### US1 - Escolher nickname
Como jogador, quero introduzir um nickname para me identificar no jogo.
**Critérios de aceitação:**
- O campo aceita texto
- O botão de entrar fica ativo após preencher

### US2 - Iniciar jogo contra o robot
Como jogador, quero conseguir iniciar um jogo contra a ai do site.
**Critérios de aceitação:**
- Existe uma opção visível para jogar contra o robot
- Ao selecioná-la, o jogador é encaminhado para o ecrã de preparação do jogo
- O tabuleiro do jogador é apresentado

### US3 - Posicionar os navios
Como jogador, quero posicionar os meus navios no tabuleiro para preparar a batalha.
**Critérios de aceitação:**
- O jogador consegue colocar todos os navios no tabuleiro
- Não é possível sobrepor navios nem colocá-los fora do tabuleiro
- Existe uma opção para posicionar os navios aleatoriamente
- O botão para iniciar a batalha só fica ativo depois de todos os navios estarem posicionados

### US4 - Disparar sobre o tabuleiro adversário
Como jogador, quero escolher uma célula do tabuleiro adversário para atacar os navios do robot.
**Critérios de aceitação:**
- O jogador consegue clicar numa célula do tabuleiro adversário
- A célula atacada muda de estado, indicando se foi acerto ou falha
- Uma célula já atacada não pode ser atacada novamente
- Após a jogada do jogador, o robot responde com a sua jogada
